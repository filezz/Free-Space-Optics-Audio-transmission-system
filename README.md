# Free Space Optics (FSO) Laser Audio Transmission

A hardware project that successfully transmits an analog audio signal over a laser beam using Amplitude Modulation (AM). This repository contains the complete circuit designs and PCB layouts for both the transmitter (TX) and receiver (RX) boards, developed from breadboard prototype to fully routed KiCad project.

## System Architecture

The project is divided into two physically separate hardware modules:

### 1. Transmitter (TX)
The transmitter is responsible for converting an incoming analog audio signal into an optical signal.
* **Core Mechanism:** Functions as a voltage-controlled current source.
* **Modulation:** Utilizes Amplitude Modulation (AM) to continuously vary the intensity of a laser diode in direct proportion to the incoming audio waveform.

### 2. Receiver (RX)
The receiver detects the modulated light and reconstructs the original audio signal for playback.
* **Sensor:** A BPW34 photodiode detects the variations in laser intensity.
* **Amplification:** The microampere current generated by the photodiode is converted to a usable voltage using an LM318 operational amplifier configured as a Transimpedance Amplifier (TIA). 
* **Signal Processing:** The TIA output is passed through active filtering stages to remove high-frequency noise and stabilize the feedback loop, then fed into an audio amplifier to drive headphones or a standard speaker.

## Hardware & Tools
* **EDA Software:** KiCad 9
* **PCB Specifications:** Custom 2-layer Through-Hole Technology (THT) layout featuring dedicated ground pours for EMI shielding.
* **Key Components:**
  * BPW34 Photodiode
  * LM318 High-Speed Operational Amplifier
  * Laser Diode Module
  * Analog Audio Amplifier IC (e.g., LM386)
